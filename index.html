Agent workflows my team runs every day

Our repo keeps a shared library of 13 agent skills for Claude Code and Cursor. I wrote the Sentry triage and Jira bug analyser skills, and I've committed to 7 of the 13.

Built from scratch

Sentry triage agent

Give it a Sentry issue link and it decides whether the error is ours, whether it's real or noise, and whether it's already known. Only then does it write a triage plan with a root cause and a proposed fix. A person approves each next step.

  1. Ownership checkIs the error in our code or the SDK boundary?
  2. Noise filterDrop network blips and known browser noise.
  3. Duplicate searchMatch similar issues from the last 45 days.
  4. EvidenceVersion, environment, browser and stack trace.
  5. Triage planRoot cause and proposed fix, written to a file.
  6. Human decisionFix it in the repo, file a Jira bug, or both.
